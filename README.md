# جَازن اسبريسو بار | الموقع الرسمي

موقع لكوفي **جَازن اسبريسو بار**، شارع أبو عبيدة الجراح، حي السويس، جيزان.
عربي بالكامل واتجاه RTL، بدون أي إطار عمل أو خطوة بناء، HTML/CSS/JS فقط.
نفس هيكل مشروع سونق: موقع + منيو باركود + لوحة تحكم Supabase.

**النشر:** على Netlify، مجلد النشر `site/` (الإعدادات في `netlify.toml`). يوسف يتولى الرفع.

## البنية

```
├── netlify.toml            إعدادات النشر والكاش على Netlify
├── reference/              مواد العميل المرجعية، لا تُنشر
│   ├── products/           صور أصنافهم الـ26 من منصة منيوهم
│   ├── ambience/           صور الأجواء التسع المختارة من قوقل ماب
│   ├── maps/               (يُنشأ من سكربت الجلب عند الحاجة)
│   ├── contact-sheet.jpg   لوحة مصغرات صور قوقل الـ45 للاختيار
│   └── menu-data.json      منيوهم كاملاً كما سُحب من منصتهم
├── scripts/                جلب المواد (شغّال عبر GitHub API، وActions معطلة حالياً)
└── site/                   مجلد النشر
    ├── index.html          الرئيسية
    ├── menu.html           المنيو (وجهة باركود QR)
    ├── admin.html          لوحة تحكم المنيو (تسجيل دخول)
    ├── supabase/schema.sql مخطط قاعدة البيانات كاملاً
    └── assets/             css / js / img / fonts (كلها ذاتية الاستضافة)
```

## الهوية

مستخرجة من مصادرهم، لا مخترعة. المصدر مذكور مع كل عنصر.

### الفكرة المركزية: لافتة مضيئة طوال الليل

المكان بار صغير يشتغل **24 ساعة طوال الأسبوع**، وأبرز ما فيه
**لافتته الأمبر المتوهجة بحروف حمراء** فوق واجهة ألواح خشب رأسية.
الموقع مبني حولها: هيرو ليلي تشتعل فيه اللافتة (معاد بناؤها CSS بنفس
تكوينها: JAZN يسار، Espresso Bar وسط، جَازن يمين)، وأقسام نهارية
بكريم شارة لوقوهم.

### عنصر التوقيع

**اللافتة تشتعل**: عند فتح الصفحة تومض اللافتة ومضات فلورسنت قصيرة ثم
تثبت متوهجة (keyframes بdrop steps خلال 1.1 ثانية). `prefers-reduced-motion`
يعطلها وتظهر ثابتة.

### الألوان (كلها معيَّنة من بكسلات صورهم)

| التوكن | القيمة | المصدر |
|---|---|---|
| `--night` | `#241811` | عتمة داخلهم الدافئة (g27)، معمَّقة درجة |
| `--amber` | `#F3C44A` | توهج اللافتة (g07) |
| `--amber-core` | `#FEF05F` | قلب التوهج، من مركز اللافتة |
| `--sign-red` | `#BF4F0F` | حروف JAZN على اللافتة (أغمق 12% من بكسلات المنطقة) |
| `--cream` | `#FBF6F2` | خلفية شارة اللوقو في إنستقرام |
| `--wood` / `--wood-deep` | `#B8935E` / `#7C5922` | خشب البار (g11, g19) |
| `--terra` | `#95552F` | جدار التراكوتا الداخلي (g14) |
| `--logo` | `#886460` | حروف اللوقو، من قلب خطوطها |

أكسنت واحد: الأمبر. أحمر الحروف يعيش داخل اللافتة فقط لأنه جزء من رسمها.

### الأشكال والموتيف

- البطاقات والصور 14px، الأزرار حبة كاملة، اللافتة وحدها 10px. لا رابع لها.
- بطاقات المحصول بأسلوب «الخانة المضيئة» مثل رفوفهم: توهج علوي داخلي وحد خشبي.
- أسفل الهيرو خامة ألواح الخشب الرأسية من واجهتهم (repeating-gradient).

### المحتوى

- «مساحة صغيرة قهوة عظيمة» و«نستقبلكم 24 ساعة» = بايو إنستقرامهم حرفياً.
- `A sip of joy` = تاق لاينهم في التذييل.
- قسم «القائمة تبدأ من المحصول»: ستة محاصيل × ثلاث تحضيرات، وهي البنية
  الفعلية لمنيوهم. كلمة «محصول» تكررت 35 مرة في تقييمات قوقل.
- الاقتباس في قسم المكان حرفي من تقييم حقيقي، والتقييم 4.8 من 440 (وقت السحب 2026-08-09).
- أسماء الأصناف والأسعار منقولة بإملائهم من منصة منيوهم
  (`jazn-espresso-bar.menus-sa.com`)، محفوظة في `reference/menu-data.json`.
- الوردمارك مستخرج من صورة بروفايلهم (حروف بشفافية، نسختان: بلون اللوقو وبالكريمي).

## قاعدة البيانات (Supabase)

**نفس مشروع سونق، لكن كل شيء في مخطط مستقل اسمه `jazn`** — لا يلمس
`public` ولا جداول سونق إطلاقاً. جدولة keepalive حقت سونق تكفي المشروعين.

- `jazn.menu_items` — الأصناف. القراءة عامة والكتابة للموظفين (RLS).
- `jazn.staff` — المصرح لهم. المدير (`is_owner`) وحده يدير الموظفين.
- `jazn.site_settings` — تقييم قوقل، مع دالة تحديث يومي عبر SerpApi
  (placeId جَازن مضبوط في الدالة، يبقى تعبئة مفتاح SerpApi).

خطوات التفعيل (مرة واحدة):
1. نفّذ `site/supabase/schema.sql` في SQL Editor.
2. Settings → API → **Exposed schemas: أضف `jazn`** (بدونها ما تشتغل الواجهة).
3. أنشئ حساب الإدارة: Authentication → Users → Add user
   بالإيميل `jazn.mng@jazn.local`، والدخول في اللوحة باسم `jazn.mng`.
4. عبّئ `SUPABASE_URL` و`SUPABASE_ANON_KEY` في `site/assets/js/config.js`.

المنيو الثابت مدمج في `menu.html`، فلو تعطلت القاعدة أو ما رُبطت بعد،
الباركود لا يتعطل أبداً.
